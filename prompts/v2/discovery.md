# Engine v2 discovery stage

Use the v2-product-researcher role. Read the compiled mission contract and current product, then
produce a structured discovery report. Challenge proposed solutions while preserving the founder's
problem, explicit boundaries and verified current behavior.

Required output: facts, user statements, assumptions, unknowns, evidence for, evidence against,
current alternatives, smallest valuable wedge, measurable outcomes, kill/continue thresholds,
three or fewer value proposals, and owner decisions. No code changes.
